# covid-stats

## Описание  
Covid-Stats — это небольшое веб-приложение, созданное с помощью Create React App и Recharts, предназначенное для отображения статистики по коронавирусу (COVID-19).  
Проект позволяет визуализировать данные, например: общее число случаев, количество выздоровевших, смертей, а также тренды по датам.

## Начало работы  
### Требования  
- Node.js и npm (или yarn)  
- Подключение к интернету (для загрузки статистики)  
- Базовые знания React или желание изучать  

### Установка  
``bash

# Устанавливаем зависимости
